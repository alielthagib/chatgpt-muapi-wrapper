Privacy Policy

Last updated: July 6, 2026

This service connects a custom ChatGPT action to an image generation API. It is used to send image generation prompts and related settings to the generation provider.

Information We Process

When you use this action, we may process the prompt you provide, the selected model, the selected aspect ratio, and technical request information required to complete the generation.

How We Use Information

Information is used only to submit generation requests, check generation status, and return generation results to the user.

Third-Party Services

This action sends generation requests to MuAPI or related generation services. Those services may process the prompt and generation request according to their own policies.

Data Storage

This service does not intentionally store user prompts or generated outputs in its own database. Some technical logs may be temporarily processed by hosting or API providers for security, debugging, and service operation.

Data Sharing

We do not sell user data. Data is shared only with service providers required to complete the generation request.

Contact

For privacy questions, contact the owner of this GPT.
